# Protótipos arquivados

Este diretório preserva o material original apenas como referência histórica.
Ele não faz parte dos workspaces, scripts, build ou execução do Hidden Route
atual.

- Não execute estes protótipos como serviços de produção.
- Não adicione credenciais, dados pessoais ou arquivos `.env` ao legado.
- Instale dependências somente quando precisar estudar um protótipo; pastas
  `node_modules` permanecem ignoradas pelo Git.
- A aplicação mantida está em `apps/web` e `apps/api`.
